# 🌐 Muskan Kamran — Personal Portfolio Website

Welcome to the repository of my personal portfolio website! This project showcases my professional experience as a **Software Engineer** and **Full-Stack Web Developer**, highlighting my technical projects, core services, research background, and interactive AI applications.

## 🌟 Key Features
- **Responsive & Modern UI:** Fully adaptive design with smooth scroll and clean layouts for all screen sizes.
- **Featured Projects Section:** Showcases key projects including an **AI Portfolio Assistant Chatbot** (Streamlit & Scikit-Learn) and an **Age Calculator** web app.
- **Interactive AI Integration:** Features a dedicated AI Assistant to answer recruiter and visitor FAQs regarding skills, degree, and background.
- **Direct Contact Options:** Quick access for hiring or collaboration via Email and WhatsApp.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla ES6)
- **Styling & Icons:** Custom CSS Variables, FontAwesome Icons, Google Fonts (Poppins & Sacramento)
- **Version Control & Hosting:** Git, GitHub,

## 🚀 Projects Included
1. **AI Portfolio Assistant Chatbot:** NLP-driven conversational bot built with Python, Scikit-Learn (TF-IDF), and Streamlit.
2. **Age Calculator:** Interactive JavaScript web app for precise date calculations.
